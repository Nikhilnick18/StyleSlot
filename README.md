# StyleSlot – Salon Appointment Booking Platform

StyleSlot is a modern salon appointment booking platform designed to make discovering salons and booking appointments simple and convenient.

Users can explore salons, view available services, check pricing, and book appointments through an intuitive interface.

## ✨ Features

- **Salon Discovery:** Explore different salons and their services.
- **Salon Details:** View salon information, available services, and pricing.
- **Appointment Booking:** Book salon appointments with customer and service details.
- **Authentication:** User registration and login using Firebase Authentication.
- **Appointment Management:** Manage booking information through Firebase.
- **Responsive UI:** Clean and responsive design across different screen sizes.

## ⚙️ Getting Started

### 1. Clone the repository

git clone [https://github.com/Nikhilnick18/StyleSlot.git](https://github.com/Nikhilnick18/StyleSlot.git) cd StyleSlot

### 2. Install frontend dependencies

cd frontend npm install

### 3. Configure environment variables

Create a `.env.local` file inside the frontend directory and configure the required Firebase environment variables.

### 4. Start the frontend

npm run dev

### 5. Backend Setup

Navigate to the backend directory, install dependencies, configure the required environment variables, and start the backend server using the configured npm script.
